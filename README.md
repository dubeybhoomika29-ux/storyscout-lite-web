# StoryScout Lite — Upload-enabled public website

Real-data-only Gradio app; designed to deploy as a Render Python Web Service from GitHub.

- Build: `pip install -r requirements.txt`
- Start: `python app.py`
- Render Free: uses ephemeral storage; uploaded research is per visitor session
- Source research CSVs may be committed in `data/` for public preload
- See `START_HERE.md` for updating an existing deployment and uploading files

The eight-factor Industry Content Index is based on human assessment, not automatic video interpretation. The default 80/100 reference is an editorial placeholder until at least five distinct competitor videos have been fully reviewed.
