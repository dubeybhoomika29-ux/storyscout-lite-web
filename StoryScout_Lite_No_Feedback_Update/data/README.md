- lite_competitor_reels.csv
- lite_trends.csv
- lite_ici_reviews.csv

The app loads these on startup. Uploading files through the website DOES NOT update this folder.
Download your browser-session research bundle and upload sanitized CSVs here through GitHub to make them permanent.
Do not publish private Instagram Insights, API keys, passwords, copyrighted video files, or respondent data.
